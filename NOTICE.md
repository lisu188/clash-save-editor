save files used by Clash.

to identify compatibility.

Public source control must not contain retail game executables, libraries,

write the save format, including offsets, sizes, value ranges, and observed
behavior. Retail-dependent validation must use a lawfully obtained local copy
and keep resulting proprietary artifacts outside the repository.
