# Original-game scenario acceptance

## Result and scope

The original-game acceptance route passed on 2026-09-26: **Load Game → inspect
both players' armies/buildings → human movement → North/South/North turn cycle →
in-game save → reload → save the restored state**. The unmodified retail binary
ran silently inside Wine/Xvfb. No debugger, game-memory writes, patched binary or
state shortcuts were used.

The fixture was generated by `:core:writeAcceptanceFixture` through public
`SaveDocument` commands. It has two human players, North and South, one type-1
light-infantry army and one type-2 building each. Export validation returned no
issues. This is acceptance of that free-game scenario and route, not a claim of
AI, campaign, combat or every editor operation being validated in the original.

The original's System → Save Game action wrote slot 1 as `turntwo`. System → Load
Game then loaded that slot. A second System → Save Game action wrote slot 2 as
`reloaded`, allowing the shipped MCP server to verify the restored state.
Both game-authored DAT files are exactly 586,414 bytes.

| Verified property | Editor export | Original save, slot 1 | Original save after reload, slot 2 |
| --- | --- | --- | --- |
| Turn | 1 | 2 | 2 |
| Acting player | 0 / North | 0 / North | 0 / North |
| Active players / armies / buildings | 2 / 2 / 2 | 2 / 2 / 2 | 2 / 2 / 2 |
| Physical army 0, row/column | 4 / 4 | 4 / 3 | 4 / 3 |
| Physical army 0, facing / units | 0 / 1 | 0 / 1 | 0 / 1 |
| Physical army 1, row/column | 12 / 12 | 12 / 12 | 12 / 12 |

The human action was a normal army selection followed by a short Alt+Up key
press. The recovered `WorldMap_RunHumanTurnLoop` implements forward movement for
that shortcut; starting facing 0 changes column 4 to 3. Captures show the
animation and completed move, and the game-authored DAT independently confirms
the new coordinates. The North and South turn banners and the displayed turn-2
counter establish the complete turn cycle.

## Reproduction

`tools/validate-original.sh` runs only under Linux/WSL. Its `start` mode copies a
known working Wine prefix and a minimal original-game session into a fresh native
`/tmp/clash-editor-validation.*` directory. Original retail assets are linked for
reading; writable `save/` and `output/` directories are isolated. The original
binary is checked against the installed original before launch. Audio drivers
are disabled and the 640×480 Wine desktop runs inside an 800×600 Xvfb server.

```sh
bash tools/validate-original.sh start "$REFERENCE" "$EXPORTED_DAT" "$EVIDENCE"
bash tools/validate-original.sh capture "$EVIDENCE" startup
# Confirm the intro is visible before dismissing it; do not send blind Escape.
bash tools/validate-original.sh input "$EVIDENCE" key Escape
# Inspect the captured window tree, focus the game window, then drive its menus.
bash tools/validate-original.sh input "$EVIDENCE" windowfocus "$GAME_WINDOW"
bash tools/validate-original.sh relative "$EVIDENCE" 150 100
bash tools/validate-original.sh input "$EVIDENCE" mousedown 1 sleep 1 mouseup 1
bash tools/validate-original.sh capture "$EVIDENCE" milestone
# After saving through the original game's UI:
bash tools/validate-original.sh collect-save "$EVIDENCE" 1 game-authored
bash tools/validate-original.sh stop "$EVIDENCE"
```

Wine DirectInput consumes relative XTest motion. In this setup, an absolute X11
warp also generated game-visible movement and cancelled accumulated deltas when
used to recenter. The verified method is **relative motion only**, without
recentering and without `--sync`; deltas continue to reach DirectInput while the
host pointer is confined. The game scaled raw deltas by approximately 0.3125.
The harness's `relative` mode uses this verified method. Capture feedback
determines the target; it does not inspect or patch game state. Cursor artwork
has an approximately 8-pixel offset from its hit point, which matters when
choosing a save row.

The source-backed interaction route is:

1. Main-menu Load, select slot 0, then the Load button. Verify the world before
   continuing.
2. Select North's light infantry and hold Alt+Up for about 80 ms. Wait for its
   movement animation to finish.
3. Hover at the top edge to expose the menu, then click End Turn. Dismiss each
   player banner with a held mouse click. Select South's army with Next Unit to
   verify its roster, then end South's turn and dismiss North's banner.
4. Hover at the top edge; hold System, drag while held to Save Game, then release.
   The original dropdown stays open only while the mouse button is held. Save is
   the third row and Load the fourth. Select empty slot 1, enter `turntwo`, then
   use a held Return press to confirm.
5. Repeat System → Load Game, select slot 1 and click Load. Confirm the restored
   army and turn-2 counter. Save separately to slot 2 as `reloaded`, collect both
   pairs and compare them through the shipped MCP.
